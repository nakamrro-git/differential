微分の視覚化イメージ 平均変化率と接線・極限

割線の傾き (Δy/Δx) において Δx → 0 とすることで、接線の傾き（微分係数）へ収束する様子をビジュアル化

1. 平均変化率（割線の傾き）

曲線 y = f(x) 上の2点 P(a, f(a)) と Q(a+Δx, f(a+Δx)) を結ぶ直線の傾きです： 平均変化率 = Δy / Δx = ( f(a + Δx) - f(a) ) / Δx

2. Δx を 0 に近づける（極限）

点 Q を点 P に向かって無限に近づけていきます（Δx → 0）。2点間の距離は小さくなり、割線はだんだんと点 P における曲線の勢い（接線）に近づきます。

3. 微分係数（接線の傾き）

Δx → 0 の極限値が点 P における微分係数 f'(a)（瞬間の変化率＝接線の傾き）です： f'(a) = lim Δx → 0 ( Δy / Δx )
